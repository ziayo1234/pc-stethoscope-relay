# PC 청진기 연결 서버

PC 청진기 3.0의 "휴대폰으로 찍기"에 쓰는 연결 서버와 휴대폰 사진 진단 웹앱입니다.

- `server.py`: 휴대폰 웹앱 파일을 주고, PC와 휴대폰 사이 암호문을 방 번호별로 넘깁니다. 파이썬 표준 라이브러리만 씁니다.
- `web/`: 휴대폰 웹앱. 사진은 휴대폰 안에서만 분석하고 보내지 않습니다.

## 개인정보
- PC와 휴대폰은 QR 주소의 `#` 뒤에 든 키로 암호화(AES-GCM)해서 주고받습니다. `#` 뒤는 서버로 가지 않아서 서버는 내용을 읽을 수 없습니다.
- 서버는 디스크에 저장하지 않고 접속 기록도 남기지 않습니다. 방은 연결을 끊거나 20분 동안 쓰지 않으면 지웁니다.

## 실행
```
python server.py   # PORT 환경 변수, 기본 8950
```
Render에는 `render.yaml`(Docker, 무료)로 올립니다.
